🎓 Sakola - School Landing Page
A modern, responsive landing page for Sakola, a world-class educational institution. This project showcases the school's advantages, diverse courses, and student achievements with a clean and professional UI.

🌐 Live Demo: https://bijoysahadev.github.io/Sakola-School-Landing-Page/

✨ Features
Hero Section: Engaging headline highlighting the school's global ranking and quality.

About Us: Clear breakdown of school advantages (Quality, Affordability, and Professionalism).

Reputation Section: Showcasing student excellence on national and international stages.

Course Selection: Grid layout featuring popular subjects like Computer Science, Design & Art, Business Studies, and Mathematics.

Newsletter: Subscription section for updates and news.

Responsive Design: Built to look great on desktops, tablets, and mobile devices.

🛠️ Technologies Used
HTML5: Semantic structure for better SEO and accessibility.

CSS3: Custom styling, Flexbox, and Grid for the layout.

Google Fonts: Integration of modern typography.

FontAwesome / Custom Icons: For visual navigation.
